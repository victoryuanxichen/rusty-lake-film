# 審查清單與錯誤圖鑑

縮圖會騙人：每個鏡頭都要看 1920 寬的原尺寸 audit 圖，並用 ffmpeg 把臉、手、帽子裁出來放大 2–4 倍看。

```bash
node render.mjs --audit --points=.3,.7 --out=out/audit
ffmpeg -y -loglevel error -i out/audit/shot00-30.png -vf "crop=760:480:330:290" out/check/faces.png
node render.mjs --sheet=8.4 --crop=880,540,160,140 --w=640 --out=out/check/hands.jpg     # 某一時刻的局部
node render.mjs --strip=4.6:5.9 --cols=8 --w=240 --out=out/check/seam-1.jpg              # 每個轉場
```

## 1. 畫風（每張圖）

- [ ] 人物有近黑粗描邊；五官、衣襟、袖縫的主線夠粗
- [ ] 陰影都是硬邊色塊，沒有排線、沒有柔和漸層冒充陰影
- [ ] 人物在牆上有柔和的大投影、腳下有接觸陰影
- [ ] 背景是寫實手繪質感（壁紙／筆觸），沒有粗黑描邊，與人物有清楚對比
- [ ] 圓角黑框存在；Roots 配方有焦黃暗角
- [ ] 色彩符合時期配方（Paradise 只有紅色是彩色）
- [ ] 表情呆滯、憂鬱、疲憊；沒有笑臉、沒有誇張表情

## 2. 對位（最常錯，逐項看放大圖）

- [ ] 帽子坐在頭上，帽簷壓住髮際線，沒有浮空或陷進臉
- [ ] 頭頂被頭髮蓋住，沒有光頭
- [ ] 髮絲線沒有畫到額頭或臉上
- [ ] 脖子的描邊停在領口，沒有穿進衣服
- [ ] 手接在手臂／袖口末端，沒有浮在衣服上
- [ ] 手的形狀可讀：看得出手掌和手指，不是黑色一團
- [ ] 交疊的手是一隻壓在另一隻上（`foldedHands`）
- [ ] 耳朵大小合理、貼在頭側（面具人不畫耳）
- [ ] 鬍子、捲髮、髮飾跟著頭一起轉（同一個變換）

## 3. 比例與構圖

- [ ] 頭寬 ≈ 肩寬 40–48%
- [ ] 最高的物件（帽子、鹿角）完整，沒有被畫面頂端或字幕條切掉
- [ ] 人物沒有被左右邊框切掉臉
- [ ] 鏡頭推近、平移時畫面邊緣沒有露出黑色的世界外圍
- [ ] 每個鏡頭只有一個異動，觀眾讀得出來

## 4. 動作與轉場

- [ ] 呼吸每人不同相位；眨眼錯開
- [ ] 異動有緩動，突兀動作前有預備
- [ ] 滴落是拋物線、落地濺開、血漬隨時間變大
- [ ] 每個轉場的 strip 沒有跳幀、空幀；閃光／轉黑的時機對上快門或燈滅的聲音
- [ ] 鐘擺、心跳、秒針對拍

## 5. 錯誤圖鑑（實際發生過）

| 版本 | 錯誤 | 原因 | 修法 |
|---|---|---|---|
| v1 | 整片是暗調噴槍油畫、沒有描邊 | 把 Rusty Lake 理解成「陰暗氛圍」而非後期畫風 | 先看使用者參考圖與遊戲截圖再定規則 |
| v1 | 紙紋變成垂直刮痕，再改成斜向後像下雨 | 噪聲在單一方向拉長 | 紙紋只用等向的斑駁＋細顆粒，強度低 |
| v2 | 線太細、陰影用排線 | 沒對照原尺寸截圖 | 線 5.6px、陰影改 `tone()` |
| v2 | 人物像假人 | 頭寬只有肩寬 30% | 頭放大 1.28 倍 |
| v2 | 新娘頭髮像頭巾／兩支角 | 後髮框住臉、前髮做成兩片長條 | 中分的 `hairCap`＋下顎處螺旋捲 |
| v3 | 帽子浮在頭上、頭頂光禿 | 改了臉的原點，帽子還用舊的絕對座標 | 頭飾全部用 fw/fh 倍數、在同一變換裡畫 |
| v3 | 髮絲線畫到額頭 | 筆觸終點低於髮際線 | 終點收在髮際線，只有兩側能往下 |
| v3 | 脖子線穿進衣領 | 脖子固定畫到 1.7 fh | `neck` 參數算到領口 |
| v3 | 面具人的耳朵像耳機 | 面具人也畫了大耳朵 | 面具人不畫耳 |
| v3 | 女僕的手是兩團黑塊、浮在圍裙上 | 縮小的手描邊太粗；袖子停在腰側沒接到手 | `foldedHands()`；小手限制線寬 |
| v3 | 鹿頭像紙箱 | 長方形頭、沒有眼窩和口鼻收窄 | 上寬下窄頭型、深眼窩、淺口鼻、大黑鼻 |
| v2 | 右邊露出黑條 | 鏡頭平移超出世界範圍 | 平移量 ≤ (z−1)·W/2 |
| v2 | 字幕條蓋住鹿角 | 推近時最高物件跑到頂端 | 人物縮小或降低鏡頭中心 |
| v1 | 鏡頭還沒衝進窗戶就先白屏 | 縮放曲線太慢、閃光太早 | 縮放到窗戶填滿畫面後才白屏 |
