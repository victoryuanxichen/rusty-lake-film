## 1. 比例

| 項目 | 值 | 備註 |
|---|---|---|
| 頭寬 : 肩寬 | ≈ 0.40–0.48 | 小於 0.35 就會像假人（第二版的錯） |
| 頭高（頂到下巴） | ≈ 2.2 fh | 含頭髮再 +0.2 fh |
| 脖子 | 短而直，寬 0.9 fw | 下緣停在領口（`neck` 參數） |
| 半身合照 | 畫到腰或大腿，下緣被畫面裁掉 | 群組再整體縮放 1.2–1.3 |
| 全身（站在門口） | 約 7 頭身，頭再放大 1.1–1.15 倍 | 腳下要有接觸陰影 |

做法：先用 kit 的 `face()` 以 `fw` 54、`fh` 70 左右畫頭，再在頭的變換裡 `c.scale(1.2–1.3)` 放大到所需尺寸；身體用世界座標畫。

## 2. 頭部座標系（`face()` 的約定）

原點在**兩眼連線的中點**；`fw` = 顴骨處半寬，`fh` = 眼線到下巴的距離。y 向下為正。

| 部位 | 位置 |
|---|---|
| 頭蓋頂 | y = −1.15 fh |
| 髮頂（`hairCap`） | y ≈ −1.34 fh |
| 髮際線 | y = −`line` × fh（預設 0.62；男性後梳 0.78–0.9） |
| 眉 | y ≈ −0.34 fw |
| 眼 | y = 0，x = ±0.42 fw，半寬 0.27 fw |
| 耳 | x ±0.95…1.26 fw，y −0.34…+0.3 fh |
| 鼻底 | y ≈ 0.42 fh |
| 嘴 | y = 0.66 fh，半寬 0.3 fw |
| 下巴 | y = 1.06 fh |
| 下顎角 | (±0.7…0.84 fw, 0.62 fh)，由 `jaw` 0→1 控制圓／方 |
| 脖子 | y 0.7 fh → `neck` × fh |

`face()` 會依序畫：脖子（含下巴下的陰影）→ 耳 → 臉型 → 臉部硬邊陰影 → 眼（眼袋、眼窩、眼白、虹膜、上眼瞼、眉）→ 鼻 → 嘴 → 皺紋。頭髮、鬍子、帽子在它**之後**畫。

主要參數：`skin`、`shade`、`iris`、`open`（0 閉眼…1 全開；常態 0.8–0.92 顯得疲憊）、`look`（[-1…1, -1…1]）、`brow`（+ 憂鬱、− 嚴厲）、`jaw`、`age`（皺紋）、`bags`（眼袋）、`lips`、`neck`、`ears`、`mask`。

## 3. 頭髮與帽子的對位

**這是最常出錯的地方**：改過頭部原點或比例後，舊的頭髮、帽子座標會整個錯位（帽子浮在頭上、頭頂光禿）。規則：

- 頭髮、帽子、鬍子一律畫在**同一個頭部變換**裡（`translate(hx, hy)` → `rotate` → `scale`），用 fw／fh 的倍數定位，不要用絕對像素。
- 頭頂一定要有頭髮：`hairCap(c, fw, fh, col, dark, { part, line, side, low, strands })`。
  - `part`：分線的 x（0 中分，−0.3fw 旁分，`null` 後梳）。
  - `line`：髮際線高度（越大越高）。
  - `side`：兩側寬度（蓬鬆髮 1.1）；`low`：兩側往下蓋到哪（正值蓋過耳朵）。
- 帽子：帽簷中心在 y ≈ −0.75 fh（壓在額頭上、蓋住髮際線），帽冠高 ≈ 1.7 fh，帽簷寬 ≈ 2 fw。畫完頭髮再畫帽子。
- 女性髮量大時，先畫「後髮」大形（在 face 之前，世界座標或頭部座標都可），再畫 face，最後 hairCap 和捲髮、髮飾。
- 老婦人：兩側蓬起的波浪髮（各自一塊＋幾條波浪筆觸）＋hairCap＋小帽。

## 4. 身體與衣服的搭法

順序（後到前）：後髮 → 外套大形 → 外套陰影 tone → 袖縫線 → 襯衫 → 背心 → 翻領 → 領巾／蝴蝶結 → 領口 → 頭（含脖子）。

- 外套大形是一個肩膀圓滑的梯形（`smooth`，下緣超出畫面），用圖案填色（`houndstooth`／`tweed`）。
- 立體感：暗側一整條 `tone(..., '#000', .28)`；手臂靠兩條粗的袖縫線（`brush`, LW×0.8）讀出來。
- 白衣：底色＋大塊灰色陰影＋褶痕楔形＋幾條細褶線；泡泡袖底部 tone＋收褶短線＋袖口粗線。
- 領口位置決定 `neck`：`neck = (領口世界 y − hy) / (scale × fh)`。脖子線不能穿過衣領（第三版的錯）。

## 5. 手

- 自然下垂：`hand(c, x, y, s, a, skin, { flip, curl })`，接在袖口／手臂末端，`flip` 讓左右手鏡像。
- 放在胸口：`hand` 旋轉 −2.0 rad 左右，`curl` .5、`spread` .25，袖子要從身側一路畫到手腕。
- 交疊在腰前（僕人、哀悼者、肖像）：**用 `foldedHands()`**，它會畫前臂從手肘斜收、白袖口、一隻手壓在另一隻上。不要拿兩個 `hand()` 並排擺（第三版的錯：手浮在圍裙上、手指像黑色梳齒）。
- 手很小時（縮放 < 0.7），描邊會吃掉形狀；`hand()` 已自動把線寬限制在 4.6×s，還是糊的話就改用 `foldedHands()` 或把手藏進袖子。

## 6. 面具與動物頭

- **面具人**：`face({ mask: true })` 畫白色面具＋黑色眼洞＋洞裡的真眼睛＋裂紋，再加 `hairCap` 深色頭髮。不畫耳朵（第二版的錯：耳朵像耳機）。
- **動物頭**（見 `examples/s03-paradise.js` 的鹿頭）：
  - 頭型上寬下窄：額頭最寬、往口鼻收窄，口鼻有一塊淺色、大的黑鼻頭（亮點＋鼻孔）。
  - 眼睛分得開、黑色杏形、外圍一圈深色眼窩、一點白色反光、淚溝線。
  - 暗側 tone、鼻樑淺色帶、額頭短毛筆觸。
  - 耳朵大、杯形、內側淺色；角或耳朵畫在頭的後面。
  - 毛茸茸的粗脖子接衣領（有毛的下緣），不是一塊木板。
  - 動物頭仍然呆滯：沒有表情，只有眼神轉向。
- 其他動物照同一個公式：豬（獠牙、扁鼻）、兔（長耳、門牙）、貓頭鷹（圓臉盤、鉤嘴）、烏鴉（長喙、黑羽）。

## 7. 新角色模板

```js
import { lerp, seg, ease, easeInOut } from '../engine.js';
import { INK, LW, shape, smooth, tone, brush, face, hairCap, hand, houndstooth } from './kit.js';
const blinkAt = (t, list, d = .15) => { let o = 1; for (const b of list) { const k = Math.abs(t - b) / d; if (k < 1) o = Math.min(o, k); } return o; };

export function gentleman(c, t, { x = 960, hy = 300, s = 1.28 } = {}) {
  c.save(); c.translate(0, -(Math.sin(t * 1.6) * .5 + .5) * 1.2);           // breathing
  // 1. body (world coords): coat silhouette, shadow side, sleeve seams
  const coat = shape(c, smooth([[x - 162, 1110], [x - 156, 560], [x - 138, 470], [x - 90, 420], [x - 40, 396], [x + 40, 396], [x + 90, 420], [x + 138, 470], [x + 156, 560], [x + 162, 1110]], 4, false), c.createPattern(houndstooth('#4a4541', '#2e2a27', 9), 'repeat'));
  tone(c, coat, [[x + 90, 380], [x + 170, 380], [x + 170, 1120], [x + 96, 1120]], '#000', .28);
  brush(c, [[x - 104, 470], [x - 112, 700], [x - 106, 1000]], LW * .8); brush(c, [[x + 104, 470], [x + 112, 700], [x + 106, 1000]], LW * .8);
  shape(c, [[x - 44, 398], [x + 44, 398], [x + 36, 720], [x, 780], [x - 36, 720]], '#efebe2');   // shirt
  // 2. head (head coords, scaled)
  const fw = 54, fh = 70;
  c.save(); c.translate(x, hy); c.scale(s, s);
  face(c, { fw, fh, open: .82 * blinkAt(t, [1.4]), look: [lerp(-.5, 0, ease(seg(t, 1, 2))), 0], brow: -.2, jaw: .8, neck: (398 - hy) / (s * fh) + .05 });
  hairCap(c, fw, fh, '#5d3c26', '#3a2416', { part: -16, line: .72, strands: 4 });
  c.restore();
  c.restore();
}
```

把人物畫進 `layer()`，再：`wallShadow(c, L.canvas, { dx: 40, dy: 10, blur: 22, a: .45 }); c.drawImage(L.canvas, 0, 0);`

## 8. 動作掛點

| 動作 | 怎麼做 |
|---|---|
| 呼吸 | 整個人 `translate(0, -breathe × 1.2)`，每人相位不同 |
| 眨眼 | `open × blinkAt(t, [時間點])`，0.12–0.16 秒 |
| 眼神 | `look` 從看旁邊／看地上 `easeInOut` 到 [0,0]（看觀眾） |
| 抬眼 | `open` 0.42→1 搭配 `look[1]` 0.9→0 |
| 歪頭 | 頭部變換在脖子底部轉，2 秒內轉 0.1 rad；驚嚇版 0.1 秒＋反向預備 |
| 舉手 | 手臂形狀的端點和 `hand` 的位置一起 `easeOut` 插值 |
| 心跳 | 縮放 `1.05 + beatPulse(t, 8) × 0.12` |
